# مونوبولي بالبلد

لعبة أونلاين خاصة بالأصحاب، مستوحاة من مونوبولي الكلاسيكية بلوح
وأسماء وأحداث مقدسية. المرجع الكامل للقواعد: وثيقة المواصفات V1.

## الحالة الحالية (النسخة الجاهزة للنشر + تحسينات إضافية)

- ✅ كل شي من الخطوات التسع + الإفلاس الكامل + إصلاحات إعادة الدخول + قوانين كاملة + مكتبات محلية.
- ✅ **سجل أحداث مختصر** مكان لوحة "آخر خانة" القديمة بلوحة اللاعبين - بيسجل كل شي مهم (شراء، إيجار، ضريبة، بطاقة، بناء، هدم، رهن، مسكوبية، صفقات، إفلاس، نهاية اللعبة) باسم اللاعب، آخر حدث فوق.
- ✅ **أصوات بسيطة** مركّبة برمجيًا (بدون أي ملف صوتي خارجي - Web Audio API): صوت نرد عند كل رمية حقيقية جديدة (مش بتتكرر على أي تحديث تاني)، صوت مختلف لما رصيدك يزيد أو ينقص.
- ✅ **تأكيد قبل الهدم**: أي محاولة هدم دار (من بطاقة الأرض أو نافذة الدين) هلق بتطلب تأكيد صريح قبل التنفيذ، نفس أسلوب تأكيد الإفلاس.
- ✅ **تنبيهات منبثقة (toast)** بدل `alert()` المزعجة يلي كانت توقف اللعبة - رسالة الخطأ هلق تطلع فوق وتختفي لحالها، مع صوت خفيف للتنبيه على الخطأ.
- ⏳ قاعدة بيانات حقيقية بدل الذاكرة - مؤجلة (مشروع أكبر بكتير لو حبيت تشغلها بشكل دائم مش بس لأمسيات).

## ملاحظات على النشر

- راجع `DEPLOY.md` للخطوات الكاملة (Railway/Render). النقطة الأهم: غيّر `admin.key` (أو حط متغير بيئة `ADMIN_KEY`) قبل ما تشارك الرابط مع حدا.
- كل شي بالذاكرة (غرف، ألعاب، تقييمات) - إعادة تشغيل أو نشر جديد بيصفّرهم، إلا إذا فعّلت "Volume" دائم من المنصة.

## كيف تشغّلها محليًا

يلزمك JDK 17+ و Maven مثبّتين.

```bash
mvn spring-boot:run
```

بعدين افتح `http://localhost:8080` من متصفح على جهاز فيه دوران
أفقي (موبايل أو تابلت)، أو دوّر نافذة المتصفح بالديسكتوب لعرض أفقي.
